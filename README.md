### 🚀 Highlighted Academic Projects

*   ⚡ **[Data-Driven MPC for SMIB Systems using Koopman Operator Approximation](https://github.com/mahdikazeminegar/Data-Driven-MPC-Koopman-SMIB)**
    *   Designed a Data-Driven Predictive Control (DPC) framework for a nonlinear power system.
    *   Utilized a Koopman-inspired lifting function for robust stability analysis and real-time QP optimization in MATLAB/Simulink.
*   🔍 **[Event-Triggered Industrial Quality Inspection System](https://github.com/mahdikazeminegar/Industrial-Quality-Inspection-CV)**
    *   Developed a prototype automated visual-inspection system utilizing OpenCV and PyTorch (ResNet-18) for anomaly detection.
    *   Integrated an Arduino UNO as a lightweight serial HMI and SQLite for persistent data logging.
*   🌱 **[Safe Adaptive Control of Hydrogen-Diesel Dual-Fuel Engines (MPC-RL)](https://github.com/mahdikazeminegar/Safe-Control-Hydrogen-Diesel-Engine-MPC-RL)**
    *   Designed a hybrid Model Predictive Control and Reinforcement Learning architecture.
    *   Addressed safety-critical environmental constraints, minimizing NOx emissions and controlling Maximum Pressure Rise Rate.
*   🚗 **[Active Suspension Control of a Four-DOF Half-Car Model](https://github.com/mahdikazeminegar/Active-Suspension-Control-LQG-LTR)**
    *   Implemented multivariable state-space modeling and LQG/LTR controller design in MATLAB to minimize body oscillations.
*   🧠 **[Neural Network-Based Nonlinear Function Approximation](https://github.com/mahdikazeminegar/Nonlinear-Function-Approximation-MLP)**
    *   Designed an MLP architecture using Backpropagation to approximate complex nonlinear behaviors for AI-based modeling.
